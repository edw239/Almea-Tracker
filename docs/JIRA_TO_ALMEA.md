# Jira → Almea

Шпаргалка для проджекта, который вёл доски в Jira.

| В Jira | В Almea |
| ------ | ------- |
| Проект | Пространство. Ключ вроде `OPS` |
| Доска по фильтру | Доска: источники (пространство, папка, список) и фильтр |
| Колонка | Набор одинаковых по названию статусов списков |
| Не на доске | Статус не попал ни в одну колонку, задачи скрыты |
| Ключ `OPS-42` | То же. Старый ключ открывается после переноса |
| Ранг | Общий порядок карточек на всех досках и в бэклоге |
| Эпик | Задача типа «Эпик», поле «Эпик» у задачи |
| Story points | Оценка. Это не учёт времени |
| Метка | Метка. Имя бренда меткой не становится — есть поле «Бренд» |
| Флажок | «Застряла» |
| Бэклог | Статус «Бэклог». Пока задача там, срок поручению не обязателен |
| Спринт | Один активный на доску. Старт ставит срок конца спринта тем, у кого его не было |
| Завершение спринта | Незавершённое уходит в бэклог, будущий или новый спринт. Совпадающий срок сдвигается и попадает в недельный обзор |
| Дорожки | Исполнитель, эпик, бренд, приоритет, запросы |
| Быстрые фильтры | Сохранённые условия фильтра, складываются через И |
| JQL | Конструктор фильтра, без своего языка |
| WIP | Показывается в заголовке колонки и не блокирует перенос |
| Отчёты | Сгорание, отчёт спринта, скорость, поток, время цикла |

Клавиши на доске: `c` создать, `/` поиск, `j`/`k` карточки, `i` открыть, `Esc` закрыть, `?` справка.
